# AGENTS.md

## Answer style

Always write your answer in ASD-STE100 Simplified Technical English (STE-100).
These rules apply to all prose in the answer. They do not apply to code, file
paths, command lines, or tool output.

### Sentences

- Write one idea in one sentence. Do not join two instructions with "and".
- Keep an instruction to 20 words or fewer. Keep a description to 25 words or fewer.
- Keep the articles (a, an, the), the relative pronouns (that, which, who), and
  the conjunctions. Do not write head-line style.
- Write short paragraphs. Use 6 sentences maximum for one topic.

### Voice and tense

- Use active voice. Name the agent. Write "The model adds a function", not
  "A function is added".
- Use the imperative for an instruction. Write "Open the file."
- Use simple present tense for a fact. Use simple past tense only for an event
  that occurred.
- Do not use an "-ing" form as a noun or to start a clause. Write "To start
  the engine, turn the key."

### Modal verbs

Use these four forms only.

- "must" for an obligation.
- "must not" for a prohibition.
- "can" for a capability or a permission.
- "cannot" for a missing capability.

Do not use "should", "may", "might", "could", "shall", or "will".

### Word choice

- Use one word with one meaning. Use the same part of speech for that word in
  the whole answer.
- Use a short common word. Write "use", not "utilize". Write "about", not
  "approximately".
- Write 3 nouns maximum in a row. Use a preposition. Write "the pressure of the
  fuel line", not "the fuel line pressure sensor value".
- Do not write "and/or". Select "or", or write both words.
- Do not use a slash or an ampersand as a word.
- Repeat the noun when a pronoun is ambiguous.
- Give a number when you can. Do not write "several" or "some".

### Structure

- Put the conditional clause first. Write "If the light is on, do not start the
  engine."
- Use a numbered list or a bulleted list for steps and for 3 or more related
  conditions.
- Keep the grammar of the items in a list parallel.

### Warnings

- Put a WARNING (risk of injury) or a CAUTION (risk of damage) before the step.
- State the hazard first, then the consequence, then the action.
- Put a NOTE after the step for more information.

### Before you answer

Check the answer for these faults and correct them: passive voice, a banned
modal verb, a sentence longer than 25 words, an "-ing" form that starts a
clause, a noun cluster of 4 or more nouns, and a missing article.
